# PianoVision — Standalone Offline Visualizer

## How to Launch
1. Double-click `index.html` to open it directly in Google Chrome, Mozilla Firefox, Apple Safari, or Microsoft Edge.
2. No Node.js, npm, terminal commands, or web server are required.
3. The app is completely client-side and works 100% offline.

## Features
- **3D Perspective Falling Notes:** Cinematic visualization with glowing notes, radiant strike line, and 88-key piano keyboard.
- **Polyphonic Piano Synthesizer:** Real-time Web Audio API sound generator.
- **Video Export:** High-definition video recording via browser-native Canvas capture and MediaRecorder into `.webm`.
- **Pre-loaded Demo:** Includes Beethoven's *Moonlight Sonata* ready to play on first launch.
